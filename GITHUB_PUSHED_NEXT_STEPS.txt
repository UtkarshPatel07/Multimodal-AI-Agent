STEP 1: GO TO RENDER.COM
───────────────────────────────────────────────────────────────────────────
1. Open: https://render.com
2. Click "Get Started" or "Sign Up"
3. Choose "Sign up with GitHub"
4. Authorize Render to access your repositories

STEP 2: DEPLOY BACKEND
───────────────────────────────────────────────────────────────────────────
1. Click "New +" → "Web Service"
2. Find and select: "Multimodal-AI-Agent"
3. Render will auto-detect render.yaml
4. Click "Apply" to use the configuration
5. **IMPORTANT:** Add environment variable:
   - Click "Environment" tab
   - Add variable:
     Key: ANTHROPIC_API_KEY
     Value: [paste your Claude API key]
6. Click "Create Web Service"
7. Wait 5-8 minutes for build
8. Copy your backend URL (e.g., https://multimodal-ai-backend.onrender.com)

STEP 3: DEPLOY FRONTEND
───────────────────────────────────────────────────────────────────────────
1. Update frontend/.env.production:
   - Replace with your actual backend URL
   - Commit and push:
     git add frontend/.env.production
     git commit -m "Update backend URL"
     git push

2. In Render dashboard:
   - Click "New +" → "Static Site"
   - Select same repository
   - Configure:
     * Name: multimodal-ai-frontend
     * Branch: main
     * Root Directory: frontend
     * Build Command: npm install && npm run build
     * Publish Directory: dist
   - Click "Create Static Site"
   - Wait 3-5 minutes

STEP 4: GET YOUR LIVE URL! 🎉
───────────────────────────────────────────────────────────────────────────
Your frontend URL will be:
https://multimodal-ai-frontend.onrender.com

Test it:
1. Open the URL
2. Upload an image
3. Ask a question
4. Get AI response!
