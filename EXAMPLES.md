## Sample Interactions

### Example 1: Circuit Diagram

**User uploads:** Circuit diagram with battery, resistors, and LED

**Text Query:** "Why does the LED light up?"

**Expected Explanation:**
"The LED lights up because current flows from the positive terminal of the battery through the circuit. The battery provides electrical energy (voltage), which pushes electrons through the conducting wires. The resistor limits the current to a safe level for the LED. When current passes through the LED, it emits light. The circuit is complete when current returns to the negative terminal of the battery, creating a closed loop."

**Annotations:** Highlights battery, resistor, LED, and shows current flow direction with arrows

### Example 2: Food Web Diagram

**User uploads:** Ecosystem food web

**Voice Query:** "How does energy flow in this ecosystem?"

**Expected Explanation:**
"Energy flows through this ecosystem in a hierarchical manner. At the base, producers (plants) capture energy from the sun through photosynthesis. Primary consumers (herbivores) eat the plants, obtaining that energy. Secondary consumers (carnivores) eat the herbivores, and so on. At each level, some energy is lost as heat, which is why there are fewer organisms at higher levels. Decomposers break down dead organisms, returning nutrients to the soil for plants to use again."

**Annotations:** Highlights different trophic levels with color coding and arrows showing energy transfer

### Example 3: Flowchart

**User uploads:** Software algorithm flowchart

**Text Query:** "What does this algorithm do?"

**Expected Explanation:**
"This algorithm implements a decision-making process. It starts by receiving input data, then checks a condition in the diamond-shaped decision box. If the condition is true, it follows the 'Yes' path and performs one set of operations. If false, it follows the 'No' path and performs different operations. After processing, it may loop back to check the condition again or proceed to output the result. This is a common pattern for iterative algorithms that process data until a certain condition is met."

**Annotations:** Highlights start/end points, decision nodes, process boxes, and flow arrows

## Tips for Best Results

### 1. Image Quality
- Use clear, high-resolution images
- Ensure text is readable
- Avoid overly complex diagrams (break into parts if needed)

### 2. Query Formulation
- Be specific about what you want to know
- Ask one question at a time
- Use follow-up questions for deeper understanding

### 3. Voice Input
- Speak clearly and at moderate pace
- Minimize background noise
- Use complete sentences

### 4. Follow-up Questions
After initial explanation, try:
- "Can you explain that part in more detail?"
- "What would happen if...?"
- "Show me where that is in the image"
- "Why is that important?"

## Advanced Usage

### Multi-step Explanations
1. Upload complex diagram
2. Ask: "Give me an overview"
3. Follow up: "Explain the first step"
4. Continue: "What happens next?"
5. Conclude: "Summarize the entire process"

### Comparative Analysis
1. Upload first image
2. Get explanation
3. Upload second image (similar topic)
4. Ask: "How is this different from the previous diagram?"

### Problem Solving
1. Upload problem diagram
2. Ask: "What is the problem here?"
3. Follow up: "How can this be fixed?"
4. Verify: "Explain why that solution works"
