📋 HOW TO GET CLAUDE API KEY
═══════════════════════════════════════════════════════════════════════

Step 1: Go to Anthropic Console
────────────────────────────────
Visit: https://console.anthropic.com/

Step 2: Sign Up or Log In
──────────────────────────
- Create an account if you don't have one
- Or log in with your existing account

Step 3: Get API Key
────────────────────
- Go to Settings → API Keys
- Click "Create Key"
- Copy your API key (starts with sk-ant-api03-)

Step 4: Add Credits (if needed)
────────────────────────────────
- Go to Settings → Billing
- Add payment method
- Add credits ($5-20 recommended)
