🚀 HOW TO USE
═══════════════════════════════════════════════════════════════════════

1. Open your web browser

2. Go to:  http://localhost:3000

3. You'll see the Multimodal Explanation System interface

4. Upload an image:
   - Click the upload area OR
   - Drag and drop an image file

5. Ask a question:
   - Type in the text box: "What is this?" OR
   - Click 🎤 "Press to Speak" and ask verbally

6. Get your explanation:
   - Read the text explanation
   - View the annotated image with highlights
   - Click 🔊 to listen to the audio explanation

7. Ask follow-up questions for more details!
