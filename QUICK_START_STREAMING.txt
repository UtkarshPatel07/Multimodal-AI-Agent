🚀 SETUP (3 STEPS):
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Install Dependencies:
   cd backend
   pip install websockets webrtcvad pyaudio

2. Start WebSocket Server:
   python backend/websocket_server.py

3. Start Flask + Frontend (as usual):
   python backend/app.py
   cd frontend && npm run dev
