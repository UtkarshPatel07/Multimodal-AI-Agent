⚡ QUICK START (3 STEPS)
═══════════════════════════════════════════════════════════════════════

Step 1: INSTALL
───────────────
Double-click:  install.bat

This installs all dependencies automatically.


Step 2: CONFIGURE
─────────────────
Edit:  backend\.env

Add your OpenAI API key:
OPENAI_API_KEY=sk-your-actual-key-here

Get your key from: https://platform.openai.com/api-keys


Step 3: LAUNCH
──────────────
Double-click:  start.bat

This starts both backend and frontend servers.


Step 4: USE
───────────
Open browser:  http://localhost:3000

Upload an image, ask a question, get AI explanation!

🔧 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════

Problem: "Module not found"
Solution: cd backend && pip install -r requirements.txt

Problem: "OpenAI API key not found"
Solution: Edit backend\.env and add your key

Problem: "Port already in use"
Solution: Edit backend\.env and change PORT=5001

Problem: Microphone not working
Solution: Allow microphone permissions in browser

More help: Check FAQ.md or SETUP_GUIDE.md
